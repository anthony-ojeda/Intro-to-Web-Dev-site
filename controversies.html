Controversies

There are a ton of controversies surrounding GitHub Copilot, and whether it can hinder a developer's skills. Some people believe that it eventually will lead to AIs essentially building our websites for us, with web developers really putting forth almost no effort at all. However, others argue that it can help web developers complete mundane and repetitive tasks quicker, so that they can focus more on things that really need to be worked on and solved.
